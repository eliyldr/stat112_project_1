# Global Automobile Sales and Multi-Country Market Impact Analysis
## Interactive Business Intelligence & Data Visualization Dashboard

### Project Overview
This project presents an interactive visual analysis of global automotive sales performance, consumer market trends, and country-level economic distributions. Built as part of the **STAT 112 (Introduction to Data Processing and Visualization)** course at **Middle East Technical University (METU)**, the dashboard explores comparative automotive metrics and market indicators across various countries.

* **Course:** STAT 112 Introduction to Data Processing and Visualization
* **Institution:** Middle East Technical University (METU), Department of Statistics
* **Author:** Elif Yıldırım
